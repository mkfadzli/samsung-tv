Pada Wi-Fi anda

Lebih kurang sepuluh minit.

TV Samsung dari 2017, Tizen 3 atau lebih baharu. Letak bandar anda dalam config.properties. Kunci TMDB percuma menambah pilihan tajuk. Gambar, bunyi, dan input kekal seperti sedia ada.

  1. Pada TV, buka Apps dan taip 1 2 3 4 5. Hidupkan Developer mode, tetapkan Host PC IP ke komputer ini, dan mulakan semula.
  2. Bina dan tandatangan. Pada TV 2023 dan lebih baharu, sijil menggunakan akaun Samsung anda.
    git clone https://github.com/mkfadzli/samsung-tv && cd samsung-tv && python3 tizen/build.py --sign <profile>
  3. Pasang. Hidupkan Autorun Last App jika anda mahu TV bangun ke dalamnya.
    python3 tizen/install.py 192.168.1.50

Cuaca oleh Open-Meteo. Waktu solat oleh JAKIM e-Solat. Pilihan tajuk oleh TMDB, yang tidak menyokong apl ini. Tiada kaitan dengan Samsung.
